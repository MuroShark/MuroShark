### 👨‍💻 Обо мне

Я разработчик ПО, переходящий в профессиональную инженерию через создание высокопроизводительных инструментов для контент-мейкеров. Моя страсть — решение сложных проблем с задержкой в экономике прямых трансляций и создание бесшовного интерактивного опыта для пользователей.

- 🔭 Сейчас я разрабатываю **LotoCroot** — альтернативу PointAuc с низкой задержкой.
- 👯 Ищу сотрудничество в **Open Source проектах для стримеров**.
- ⚡ **Философия:** Производительность, Стабильность и UX, ориентированный на геймеров.

###  Featured Project: LotoCroot

**Интерактивный сервис аукционов для стримеров**

> *LotoCroot — это специализированный сервис для прямых трансляций, который позволяет стримерам проводить аукционы в режиме реального времени. В данный момент работает как браузерный клиент; интеграция с OBS и поддержка мобильных устройств находятся в активной разработке.*

<a href="https://lotocroot.vercel.app">
  <img src="https://github.com/user-attachments/assets/9a124d4c-7753-47f8-b7e0-416684555afc" alt="LotoCroot Demo" width="100%" />
</a>

<br />

| 🎯 Ключевые возможности | ⚡ Технологии | 🛠 Статус |
| :--- | :--- | :--- |
| **Оверлей аукциона** <br> *Встраиваемый виджет для OBS/Streamlabs* | **React & Tailwind** | 🚧 В планах |
| **Система ставок Real-Time** <br> *Мгновенная синхронизация между стримером и зрителем* | **WebSockets** | ✅ Работает |
| **Панель управления стримера** <br> *Управление лотами, таймерами и победителями* | **Next.js & Zustand** | ✅ Работает |
| **Мультиплатформенность** <br> *Адаптивный дизайн для мобильных и планшетов* | **CSS / Media Queries** | 🔄 В процессе |
| **Локализация** <br> *В данный момент только русский* | **i18n** | 🔄 В процессе |
